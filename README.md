# algo

OPC : Shleep



Pitch : 

Des insomnies répétées ont troublé l’ordre des moutons de rêve, d’ordinaire chargés de maintenir un état de sommeil stable pour tous. Afin de rétablir l’équilibre, l’humain le plus sujet à ces insomnies à été invoqué dans le monde des nuages. S’il parvient à ramener tous les moutons de rêve égarés, l’ordre sera enfin rétabli.

Gameplay

Shleep est un platformer à la troisième personne dans lequel il faut ramasser des étoiles jaunes pour faire grimper son score tout en évitant les étoiles violettes, corrompues par l’insomnie et pénalisant le score. Le jeu est divisé en plusieurs niveaux, et en compléter un permet à sa fin de trouver un mouton égaré, permettant de progresser dans l’histoire.
